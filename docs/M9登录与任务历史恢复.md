# 徕卡一瞬 M9 二瞬登录循环与任务历史恢复

> **云端 M9 二瞬相关内容仅供学习参考。**

适用于小米 15 Ultra（xuanyuan）国行 OS4.0.4.0.XOACNXM 的 Hybrid68 补丁。下面两项修复都在相册编辑器 `com.miui.mediaeditor`。r11、r12 均包含相册编辑 v15，已集成这些修复。

## 1. 系统已登录，点「开始增强」仍反复要求登录

参考机点「登录」后弹窗消失，再点「开始增强」又弹出。编辑器调用 `AccountManager.getAccountsByType("com.xiaomi")` 只能看到 0 个账号，原 `addAccount` 回调也没有返回可启动的 `Intent`。此时 `uploadFile failed, not login` 出现在上传前的本地账号检查。

**上次的处理**

1. 相册编辑 v5 在用户主动点登录后保留原 `addAccount` 流程。当原回调没有 `Intent`，且编辑器仍看不到小米账号时，调用 Android 系统账号选择页，只列出 `com.xiaomi` 类型。
2. 由机主选择自己已登录的小米账号。返回编辑器后再次查询真实可见账号，查到账号后继续原有授权和二瞬处理流程。
3. 参考机授权后 `HybridGalleryAccountCount` 从 0 变成 1，上传成功。后续在相册编辑 v6 验证了完成增强、保存和重新打开成片。

**再次遇到时怎么查**

- 先确认当前运行的是对应整包中的相册编辑 APK，按解压包 `release.json` 核对 SHA-256。确认相册、编辑器和系统账号处于同一个 Android 用户。系统分身和应用双开可能使用独立账号环境。
- 可见账号仍为 0 时，查看点登录后是否进入系统账号选择页，返回后是否出现 `HybridGalleryAccountCount=1`。在编辑器自己的进程中核对这个计数。
- 编辑器已能看到账号但增强仍失败时，按日志追到具体阶段，区分授权请求、上传、建任务、取结果或保存。HTTP 401/403 需要结合失败的是哪个请求判断。
- 如需从旧版更新，可按对应补丁包说明覆盖相册编辑 APK。r12 的相册编辑文件在 `apps/MediaEditor-v15.apk`，SHA-256 为 `0cd2204997d2ae40f0854b53693ff8c9d9848d67e6bccbe34da97dd5ea2f7b75`。

维护时可在 2.10.40.4.8 编辑器基线定位 `classes2.dex` 中的 `ga0/a` 登录回调、`ga0/d` 选择结果回调和 `ga0/e` 账号读取。`yn/j` 是 M9 上传前账号检查的入口之一。账号授权由各机主在自己的手机上完成。

## 2. 右上角「编辑任务」提示网络异常，历史列表空或加载不全

参考机进入任务页时，云端列表探测和重试均返回 HTTP 401，并弹出「网络异常」。页面原有内容来自按当前账号筛选的本机任务记录，默认查询最近七天。该探测的响应没有用于填充列表。

**上次的处理**

1. 相册编辑 v7 把任务页刷新和翻页改为直接走原有本机查询，保留真实账号检查、账号筛选和原有时间范围。参考机实测重新进入任务页后显示「处理完成（39）」。实现可从 `classes2.dex` 中的 `uv/x` 和 `uv/s` 定位。
2. 当前账号切换或本机缺少记录时，本地列表可能为空。已经失效的缩略图或不再存在的文件仍可能打不开。
3. 如果点任务右侧的叉号，云端删除曾在参考机返回 HTTP 401。v8 允许从当前账号的本机列表移除已完成或失败的记录，保留原图和成片。v9 保留确认框，去掉本地移除成功后的提示气泡。正在排队或处理的任务继续使用原有云端取消流程。

## 3. 复现日志与验收

Windows PowerShell 中先用 `adb devices` 确认设备。然后开始记录，在手机上分别复现一次登录循环和「编辑任务」异常，完成后按 Ctrl+C。多台设备时给 `adb` 加 `-s` 指定目标序列号。

~~~powershell
adb logcat -v threadtime -T 1 | Select-String 'HybridGalleryAccount|CloudLegendM9|LegendaryActivity|login cancel|HTTP.*40[13]|AndroidRuntime'
~~~

- 登录验收看三个结果。应用能读取机主本人授权的账号。「开始增强」可以完成处理。保存成片后重新打开仍有效果。使用愿意上传的测试图，由机主操作。
- 历史验收用同一个账号打开右上角「编辑任务」，检查本机近期已完成任务能否显示和打开。需要验证移除时，用一条可移除的已完成测试任务，退出重进后检查列表和照片。
- 向其他人提供日志时，保留账号数量、失败阶段和错误码即可。账号名、账号 ID、令牌、Cookie 和云结果链接应去除。
