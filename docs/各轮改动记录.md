# 各轮改动记录

> **云端 M9 二瞬相关内容仅供学习参考。**

相机和相册编辑各自使用 vN 编号，整包使用 rN 编号。下表包括开发候选和当时的验收结果。最新公开版为 r16，相机 v82 与相册编辑 v16。 [公开发行版](https://github.com/Lawrence-Ding-Hare/Xiaomi15Ultra-M9-Camera/releases)

## 相机

| 版本 | 改动与结果 |
| --- | --- |
| v1 | 建立 6.8.002230 主干，逐条对照 6.7 的设备能力、渲染与保存接口。 |
| v2 | 修正设备能力类的继承，按 6.8 的任务与上下文接口接入 M9 保存。实测仍遇到街拍、人像和实况运镜崩溃。 |
| v3 | 恢复本机快速变焦、街拍镜头映射与人像裁切参数。 |
| v4 | 用原有 28 mm 构造路径传入镜头参数，修正对 final 字段的直接赋值。 |
| v5 | 校正实况运镜的四物理镜头及原生倍率区间。参考机确认街拍和实况运镜恢复。 |
| v6 | 普通拍照的 MIVI2 并行任务 16 使用快门时的 Candy 参数渲染最终 JPEG。参考机验证调色在相册重开后保留。 |
| v7 | 将传奇一瞬入口、选择面板与 M3/M9 图标统一为徕卡一瞬，参考机确认 UI。 |
| v8 | 按真实 JPEG 格式处理云水印输入，修 AI 水印的最终渲染和机型文字。花屏消失后发现部分竖拍旋转 90 度。 |
| v9 | 校正传感器坐标和 JPEG 方向。调色和水印同时开启仍可能产生双框。 |
| v10 | 按实际加框 JPEG 尺寸绘制，解决双框。调色仍会作用到边框。 |
| v11 | 把调色放到加框之前，参考机确认横竖方向正确、单框且框保持原色。 |
| v12 | 两亿像素模式增加未保存任务判断，直接点缩略图仍可绕过。 |
| v13 | 缩略图入口等待真实保存任务完成，显示高像素处理提示。实测反复快进相册后成片仍为 12288×16320 或横向尺寸。 |
| v14 | 恢复照片质量「极高」项，实测选择可保留、普通拍照可保存。 |
| v15 | MIVI2 调色保存扩展到专业 JPEG，RAW 随附 JPG 有调色，徕卡相框同样走先调色再加框。 |
| v16–v17 | 定位 AI 帮拍入口的本机能力判断。v16 入口未显示，v17 可进模式和预览，登录弹窗循环。 |
| v18–v20 | v18 接入系统账号选择。v19 单独验证服务请求的机型兼容参数，场景识别偶发成功。v20 修正运动量字段的整数序列化，多物体可重复识别。智能构图仍待适配。 |
| v21 | 「更多」增加找机位外部跳转。实测能打开已有的找机位应用。 |
| v22–v24 | v22 在匹配主摄 2× 中心裁切时写入 AISP_FOV。v23 暴露 smali 参数寄存器错误，导致 M9 落盘回退普通 JPEG。v24 修复后验证封装和 2× 构图。 |
| v25 | 携带物理 ID 4 的长焦裁切，参考机确认二瞬 4.3× 画幅及构图。 |
| v26–v28 | 试验长焦 ISP、ADRC 增益保护。新增同场景对照仍有偏紫，限幅的必要性未单独证实。 |
| v29–v30 | v29 将长焦上报的黑电平 0 按 64 转换，3× 新拍对照通过。v30 直接取同帧长焦槽校验过的黑电平。 |
| v31–v32 | v31 实验的长焦槽读取路径触发 ART 校验失败，M9 标签丢失。v32 从 v21 重做，采用验证过的同帧长焦槽参数，实测 4.3× 标签、画幅与云端色调恢复。 |
| v33 | 主摄 1×、2× 在保留既有标定的前提下调整 RAW10 Bayer 采样。书页周期纹路在同帧对照中减轻，局部细纹仍可见。 |
| v34 | 相机从同一拍摄任务补回滤镜成片缺失的镜头和曝光 EXIF。参考机手装后调色与普通相框通过。该实验在 r11 发布后完成。 |
| v35 | 修复普通与专业模式的原片调色无法写入最终 JPEG。普通 JPEG、专业 JPEG 和 RAW 随附 JPEG 实机通过。 |
| v73 | 主摄专业录像 4K30 的 Open Gate 实录验证。 |
| v74 | Open Gate LOG 支持「还原」LUT 预览。专业 4.3× 潜望拍照可达 43×。均实机通过。 |
| v75 | M9 主摄 2× 在确认物理镜头、读出模式、RAW 全幅及拍摄裁切后写入 AISP_FOV。ART 实测通过，云端新拍待复测。 |
| v77 | 人像 JPEG 的最终并行任务接入拍摄时的 Candy 参数。参考机验证对比度、饱和度与最低饱和度的灰度成片。 |
| v78 | 慢动作切到 3× 或 4.3× 物理长焦后，按该镜头基准换算裁切倍率。720P120 实录分别使用物理 ID 4、5，两颗镜头均以 1.0× 取画。 |
| v79–v80 | 扩展独立两亿像素 HEIF 的画内水印模板。经典 3（模板 19）与最低饱和度组合在 12288×16320 成片通过。 |
| v81 | 独立两亿像素等待正式写盘和任务队列清空后再进入相册。实测返回相机即可继续拍摄。 |
| v82 | 独立两亿 HEIF 新增网球图案（模板 121）。竖拍右下版式与调色组合通过，主图为 12288×16320。 |

原色能力检查中，两路公开相机的 `xiaomi.capabilities.stylizationTypeMask` 实测为 6，6.8 用于显示原色的 bit 3 未置位。独立软件实现尚待确认，公开基线未开放入口。

## 相册编辑

| 版本 | 改动与结果 |
| --- | --- |
| v1–v2 | 定位徕卡入口和相册的能力缓存。刷新后箭头可见，v2 修复 xuanyuan 上私有 API 访问异常造成的编辑闪退。入口和滤镜调色盘实测可打开。 |
| v3–v4 | 按实际滤镜索引改中文显示名称，保留原有 LUT 与参数。v3 仍见简称，v4 实机确认显示已更新。 |
| v5–v6 | 接入系统账号选择，完成本地调色保存、扩展滤镜及 M9 实际云增强保存验收。 |
| v7–v9 | 编辑任务列表使用已有本地查询。v8 允许本地移除已结束任务，实测云删除仍返回 HTTP 401。v9 去掉本地移除成功后重复的气泡。 |
| v10–v11 | 紧盯云图块边的局部色度实验，测得部分块边减轻，截图中仍有纹路或细节变化。 |
| v12 | 以原 JPEG 和云回图的亮度结构估计裁切。2× 可匹配，偏移较大的 4.3× 样本仍存在构图和紫偏。 |
| v13–v14 | 扩大裁切搜索并试验本地校色。实测改变了想保留的云端色调。 |
| v15 | 保留亮度匹配裁切并去掉本地色度校正，与相机 v32/v33 搭配验证。高置信度才裁切，低置信度保留全幅。 |
| v16 | 仅对 xuanyuan 的徕卡类别前 6 款定制模板补充机型支持，并隐藏模板 89 的 LEICA ?? 占位文字。保留原有拍摄参数校验。参考机安装后，用户确认相框正常。 |
