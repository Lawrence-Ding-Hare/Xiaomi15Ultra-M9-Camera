## 实测与待验证

- r15 相册编辑 v16 已安装到参考机，安装包与设备 APK 的 SHA-256 一致，未重启。用户确认徕卡相框正常。主机静态检查通过 DEX、包版本、V3 签名证书、ZIP/ELF 16KB 对齐和整包 28 项清单。单独逐项测试六个模板以及其他 OS4.0.4.0 设备仍待验证。

- r14 的 Open Gate LOG LUT、专业拍照 43× 在参考机以 v74 实测通过。v75 的 M9 2× 同帧构图字段通过独立 Android ART 测试，整包实机重装及云端新拍仍待验证。
- r13 的相机 v73 在参考机实录通过。普通 8K30、超级防抖、超级防抖 Pro 和延时摄影均验证了物理 4.3×。专业录像主摄 4K30 Open Gate 实录为 4096×3072。
- r12 相机覆盖更新、普通 JPEG、专业 JPEG 和 RAW 随附 JPEG 实机通过，独立 DNG 正常落盘。整包通过主机模拟。
- r2 完整重装并自动重启一次。参考机抽测了普通拍照调色、实况运镜、M3/M9、相册编辑与调色副本。r2 保留水印和快速进入相册时可能提前中断两亿像素保存的旧缺陷。
- r4、r10、r11 的 ZIP、清单和主机安装流程检查通过。r11 在参考机覆盖了两个 APK 并做实拍抽测，整包从头安装仍待验证。参考机另一次手动重装两份 APK 后发现 M9 标记缺失，补回后新片标签和处理入口恢复。 [覆盖更新故障排查](覆盖更新故障排查.md)
- 相机 v33 的 1×、2× 新片均可进入二瞬，处理、保存及构图正常。书页放大后仍可见细纹，异常在云回图中已有。2× 偶发偏紫的外部反馈尚无故障原片与二瞬成片对照。
- 两张旧长焦故障片做了同帧黑电平对照。3× 的明显紫偏像素比例从 45.36% 降到 0%。4.3× 的历史故障云回图为 83.12%，修正后的云回图和保存件均为 0%，保存尺寸为 4223×5630。该条件下的修正已包含在 r11 的相机。
- 找机位使用原签名 1.0.21，现有入口可用时保留已装版本。AI 帮拍场景识别实测通过，智能构图暂缓。原色模式尚未开放。
- 实际账号授权依赖接收者设备。参考机的任务列表从本机读取，云端删除曾返回 HTTP 401，已结束任务可从本机列表移除。
