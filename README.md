# Xiaomi 15 Ultra M9 Camera

小米 15 Ultra（xuanyuan）的徕卡一瞬相机移植与适配项目，包含实况运镜、拍摄调色盘及配套相册编辑。每个发布版会标明适用的系统和相机版本。

> **云端 M9 二瞬相关内容仅供学习参考。**

当前 r14 适用于国行 OS4.0.4.0.XOACNXM，内含 6.8.002230.0 相机 v75。首次安装按 ZIP 内的安装入口和前置依赖说明操作。已正常运行 r13 的用户可直接覆盖更新相机 APK。 [发布与下载](https://github.com/Lawrence-Ding-Hare/Xiaomi15Ultra-M9-Camera/releases)

如果更新后 M9 标签消失、调色只在预览有效，或徕卡相框报缺少参数，可按症状核对 APK、保存日志和拍摄参数。 [覆盖更新故障排查](docs/覆盖更新故障排查.md)

- 手动重装相机后，新拍 M9 照片缺少相册标签或入口。 [重装后恢复 M9 标签](docs/M9标签恢复.md)
- 系统已登录小米账号，二瞬仍反复提示登录，或「编辑任务」历史打不开。 [恢复二瞬登录与任务历史](docs/M9登录与任务历史恢复.md)

维护者可从 [接手指南](docs/接手指南.md) 开始，查看 [版本与实测](docs/版本与实测.md)、[排查过程与教训](docs/排查过程与教训.md) 和 [脱敏验证记录](docs/脱敏验证记录.json)。

相机、相册编辑和整包各轮的改动、实测与回归记录见 [各轮改动记录](docs/各轮改动记录.md)。
