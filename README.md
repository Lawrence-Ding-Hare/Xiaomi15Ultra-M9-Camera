# Xiaomi 15 Ultra M9 Hybrid68

面向小米 15 Ultra（xuanyuan）国行 `OS4.0.4.0.XOACNXM` 的 6.8 混合相机补丁，包含徕卡一瞬、实况运镜、拍摄调色盘及配套相册编辑。

在 [Releases](https://github.com/Lawrence-Ding-Hare/Xiaomi15Ultra-M9-Hybrid68-OS4040/releases) 下载对应版本的补丁 ZIP。完整安装前先阅读包内《00-给AI看的安装入口.md》和《前置依赖.md》。已装好同系列补丁并正常运行的用户，可按 r11 包内《已安装旧版-APK覆盖更新.md》覆盖相机和相册编辑。

如果更新后 M9 标签消失、调色只在预览有效，或徕卡相框报缺少参数，可按症状核对 APK、保存日志和拍摄参数。 [覆盖更新故障排查](docs/覆盖更新故障排查.md)

维护者可从 [接手指南](docs/接手指南.md) 开始，查看 [版本与实测](docs/版本与实测.md)、[排查过程与教训](docs/排查过程与教训.md) 和 [脱敏验证记录](docs/脱敏验证记录.json)。

相机、相册编辑和整包各轮的改动、实测与回归记录见 [各轮改动记录](docs/各轮改动记录.md)。
